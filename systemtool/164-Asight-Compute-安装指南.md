# Asight Compute 安装指南

## 1. 获取 acu 命令行工具

### 1.1. 配置环境变量

acu 命令行工具包含在 T-Head SAIL SDK 中，获取 SDK 请参见[SDK 使用指南](https://developer.t-head.cn/docs_center/doc_detail/index.html?projectId=39&chapterId=194)。安装完成后，进入 SDK 目录，执行以下命令配置所需环境变量：

```bash
source envsetup.sh
```

### 1.2. 检查运行环境

环境变量配置完成后，执行以下命令查看当前安装的 acu 版本信息：

```bash
acu -v
```

## 2. 获取 Asight Compute GUI 工具

Asight Compute GUI 工具安装包单独发布，支持以下操作系统：

+ Windows 10 / Windows 11
+ macOS 10.15 及以上版本

请前往[下载页面](/download/index.html?type=TOOLS)获取安装包，根据操作系统选择对应的格式：

+ Windows 系统请选择 `.msi` 安装包
+ macOS 系统请选择 `.dmg` 安装包
