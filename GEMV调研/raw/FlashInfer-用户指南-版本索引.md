# FlashInfer-for-SAIL 用户指南

FlashInfer 是一个用于大语言模型推理的高效推理 kernel 库。本指南提供了真武 PPU 平台上 FlashInfer-for-SAIL 各个版本的安装和使用说明。

## 版本列表

### [FlashInfer-for-SAIL v0.6.12 用户指南](/docs_center/doc_detail/index.html?projectId=6&documentId=76)

本指南描述了在真武 PPU 上安装并快速使用 FlashInfer-for-SAIL v0.6.12 的步骤。

- 支持 SAIL SDK V2.1.1 Release
- 基于社区 v0.6.12 版本适配
- 支持 Docker 镜像、PyPI 源安装、从源码编译

### [FlashInfer-for-SAIL v0.6.8.post1 用户指南](/docs_center/doc_detail/index.html?projectId=6&documentId=77)

- 支持 SAIL SDK V2.1.1 Release
- 基于社区 v0.6.8.post1 版本适配
- 支持 Docker 镜像、PyPI 源安装、从源码编译
